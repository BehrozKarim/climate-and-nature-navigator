# Generated synthetic snapshot cache

`initial-snapshot.json` is generated by `backend/scripts/export_frontend_cache.py`, not edited by hand. It contains precomputed public synthetic challenge results and source provenance under the supplied CC BY 4.0 attribution recorded in the asset. It excludes chat, review notes/decisions, source documents and the original workbook. Never export private operational data into this publicly distributed asset.

Regenerate after a snapshot/calculation change, then build. Dataset and calculation fingerprints control browser invalidation; recent custom results are bounded in local storage. Saving and all mutations require the backend and obtain full evidence. See [the frontend README](../../README.md#initial-data-and-cache).
